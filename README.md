# 🎅🐸 Новогодняя Жабилизация 2027

Бот Тайного Санты для чата «Жабилизируемся».

## Что умеет

**Участник** (в личке с ботом):
- 🐸 «Участвую!»: анкета из 4 шагов:
  1. Как тебя зовут? *(обязательно)*
  2. Что бы тебе хотелось получить? *(обязательно)*
  3. Где будешь встречать Новый год? *(кнопки: 🎄 на празднике / ✈️ в другом месте)*.
     При ✈️ бот спрашивает, как отправить подарок. Это видит только Санта.
  4. Чего точно НЕ дарить? *(можно пропустить)*
- ✏️ изменить анкету или 🚪 выйти, пока не прошла жеребьёвка
- 🎁 «Кому я дарю?»: после жеребьёвки внизу экрана постоянно видна кнопка с подопечным. То же делает команда `/my` в меню Telegram.
- ❓ «Спросить подопечного анонимно»: бот пересылает вопрос без имени, подопечный может ответить Санте

**Организатор** (👑 Панель организатора):
- 💰 задать бюджет подарка (один на всех)
- 📅 задать дату обмена в формате «31.12.2026». Участникам придёт напоминание за 7 дней и за 1 день в 18:00.
  Время берётся по часам компьютера, на котором работает бот. Если бот был выключен в нужный момент, напоминание придёт сразу после включения.
- 👥 список участников: только имена и ✈️ у тех, кому нужна доставка
- 📣 «Напомнить всем»: сообщение всем участникам
- 🔔 уведомление, когда записывается новый участник
- 🎲 запустить жеребьёвку: каждый получит подопечного в личку
- ♻️ сбросить жеребьёвку: всем придёт уведомление

**В групповом чате**: команда `/santa` показывает счётчик «Уже жабилизировались: N 🐸», бюджет и ссылку на бота.

## Как запустить

### 1. Создать бота
1. Открой в Telegram [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя: `Новогодняя Жабилизация 🎅🐸`
3. Username: `tainaya_zhaba_bot` (если занят: `zhabilizacia_bot` или `tainaya_zhaba_ny_bot`)
4. Скопируй токен.

### 2. Настроить
Впиши токен в файл `.env` после `BOT_TOKEN=`.
Свой ID узнаешь так: запусти бота, напиши ему `/myid` и впиши число после `ADMIN_IDS=`, затем перезапусти бота.

### 3. Запустить
Дважды кликни `run.bat`. Бот работает, пока открыто окно.

Если окружение нужно поставить заново:
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## 🐳 Запуск на сервере через Docker

На сервере нужны git, Docker и Docker Compose v2 (команда `docker compose`).

> ⚠️ Бот должен работать только в одном месте. Перед запуском на сервере остановите его на компьютере.

### Установка одной командой

```
curl -fsSL https://raw.githubusercontent.com/<owner>/<repo>/main/install.sh | REPO_URL=https://github.com/<owner>/<repo>.git bash
```
Если репозиторий приватный, склонируйте его вручную и запустите скрипт из папки:
```
git clone <адрес репозитория> ~/zhabilizacia
cd ~/zhabilizacia && bash install.sh
```

Скрипт:
1. скачивает код в `~/zhabilizacia` (папку можно сменить переменной `APP_DIR=...`);
2. при первом запуске спрашивает токен бота и Telegram ID организатора, сохраняет их в `.env` с правами `600`. В репозиторий этот файл не попадает;
3. собирает и запускает контейнер, затем ждёт строку `Run polling for bot` в логе.

Вводить данные вручную необязательно: `BOT_TOKEN=... ADMIN_IDS=... bash install.sh`.

### Обновление после правок в коде
```
cd ~/zhabilizacia && bash install.sh
```
Скрипт подтянет свежий код с GitHub и пересоберёт контейнер. Данные и `.env` остаются нетронутыми.

### Автозапуск после отключения света
```
sudo systemctl enable docker
```
Ещё стоит включить в BIOS сервера настройку «Restore on AC Power Loss → Power On», тогда сервер сам включится, когда дадут свет.

**Полезные команды:**
| Что | Команда |
|---|---|
| Посмотреть лог | `docker compose logs -f` |
| Перезапустить | `docker compose restart` |
| Обновить после правок в коде | `bash install.sh` |
| Остановить | `docker compose down` |

### Что переживает отключение света
- Анкеты, бюджет, дата, жеребьёвка и отметки об отправленных напоминаниях хранятся в `data/zhabilizacia.db`.
- Недозаполненные анкеты тоже сохраняются: человек продолжит с того же вопроса.
- Если в момент напоминания света не было, бот отправит его сразу после включения.
- Раз в сутки делается копия базы в `data/backups/`, хранятся последние 7 копий. Чтобы восстановиться из копии: `docker compose down`, скопировать нужную копию вместо `data/zhabilizacia.db`, удалить `zhabilizacia.db-wal` и `-shm`, затем `docker compose up -d`.
- Часовой пояс для напоминаний в 18:00 задаётся строкой `TZ=` в `.env`, по умолчанию `Europe/Moscow`.

## Как провести игру
1. Добавь бота в чат «Жабилизируемся» и напиши `/santa`.
2. Все пишут боту в личку и заполняют анкету.
3. Организатор задаёт бюджет.
4. Когда все записались, организатор жмёт «🎲 Запустить жеребьёвку».
5. Дарите подарки! 🎁
